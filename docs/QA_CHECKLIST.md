# Manual QA checklist

- [ ] Clean install creates a 200-coin profile and initial booster inventory.
- [ ] Home, every menu button, Credits and Privacy open and Back behaves consistently.
- [ ] Levels 1–3 tutorials teach tap, coverage and tray pressure; replay setting resets them.
- [ ] Mystery level 31 never requires guessing a covered item.
- [ ] Key level 61 unlocks all matching locks and consumes no tray slot or Priority move.
- [ ] Priority level 91 succeeds at zero on the matching triplet and otherwise explains failure.
- [ ] Undo covers normal move, match, key, Priority and Extra Slot state.
- [ ] Shuffle changes a multi-destination board and remains solvable; Extra Slot applies once.
- [ ] Pause/resume and Android Back never accept board input behind a modal.
- [ ] Force-close after a reward/upgrade reloads correct progress; corrupt primary recovers backup.
- [ ] Level 30/60/90/120 unlocks the next world; level 150 uses mixed mechanics.
- [ ] Daily same-date replay cannot duplicate reward; next and skipped days update streak safely.
- [ ] Endless unlocks after level 20 and retains high score after restart.
- [ ] All 90 airport stages persist and never gate campaign progress.
- [ ] English/Ukrainian switch live with no raw translation keys.
- [ ] Master/SFX/haptic/reduced-motion/text-size settings survive restart.
- [ ] Check 360×640, 360×800, 390×844, 412×915, 1080×2400 and portrait tablet.
- [ ] Test Android gesture insets and rotation lock on a physical low/mid-range device.
- [ ] Airplane mode launches, saves and plays every mode without repeated errors.
- [ ] Mock ad reward success, cancel, load failure, no fill, interstitial success/failure.
- [ ] Production ad test uses Google test units/test devices and valid UMP consent first.
